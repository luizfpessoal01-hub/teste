Projeto: Landing Page Responsiva
Arquivos:
- index.html
- style.css
- script.js
- pasta img/ (imagens e ícones)

Como publicar no GitHub Pages:
1. Crie um repositório público no GitHub (ex: landing-page-responsiva).
2. Faça commit e push dos arquivos.
3. No repositório, vá em Settings > Pages (ou Pages na lateral) e selecione a branch 'main' e a pasta '/' (root).
4. Salve. O site ficará disponível alguns minutos depois no link shown pelo GitHub Pages.
